## Brand pipeline (one master → every icon)

`scripts/brand-import.py <master>` (Python + Pillow, run by hand — Pillow is not a
project dependency) crops the mark by content brightness, centres it on a square
transparent tile where the mark fills 30% (`PAD = 0.35`, the one knob: raise it for a
smaller mark, lower it for a bigger one — the tile itself is never scaled, only
the mark inside it) and writes every asset above: taskbar/exe `.ico`, favicon pair,
Tauri icon set, and the transparent in-app mark (alpha from luminance). Ship a new
logo by dropping the file in as `resources/brand/pq-master.jpg`, running the script
and committing the outputs — never by editing a derived icon alone.

## Built-in harness “logos” (letter-mark + color)

Letter monograms are the fallback only. Primary marks are the official vendor
assets in `src/renderer/src/components/engineLogos.tsx`
(Grok X, Omp π, Hermes H, OpenCode brackets, Codex prompt, Claude starburst,
Qwen hexagon, DeepSeek whale, Gemini spark, Crush C, Aider A, Copilot loop,
PowerShell prompt). External `EngineSpec.logo` / `icon` URLs still win when set.
